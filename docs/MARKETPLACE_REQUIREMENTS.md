# Marketplace Requirements

A module listing should include:

- name, short name, publisher, version, license, visibility;
- icon, cover, screenshots, and preview metadata;
- README and changelog;
- permissions with risk labels;
- surfaces and shell mode;
- docs: FILETREE, CONTEXT, RUNTIME, SECURITY, TESTING, API, MARKETPLACE;
- source repo and release ref;
- install/update/uninstall behavior;
- support and security contact.

Public marketplace review should check:

- manifest validity;
- permission accuracy;
- package file tree completeness;
- no arbitrary remote code in host-rendered mode;
- screenshots match declared surfaces;
- high-risk modules have explicit warnings and gates.
