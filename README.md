# Modula Module Standard

MMS, the Modula Module Standard, defines how modules identify themselves, declare permissions, expose UI surfaces, and participate in the Modula registry/version flow.

Current version: `0.1.2`.

This repository is private while the standard is still stabilizing.

## Contents

- `MODULA_MODULE_STANDARD.md` - normative standard.
- `schemas/` - JSON schemas for manifests, permissions, UI, data, and versions.
- `examples/` - example manifests for GitHub-backed host-rendered modules.
- `registry/modules.json` - bundled registry seed.
- `packages/types/` - TypeScript types for consumers.
