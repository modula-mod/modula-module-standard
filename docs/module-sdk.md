# Module SDK

`@modula/module-sdk` provides contract-only helpers for external module authors.

SDK helpers include:

- `defineModule`;
- `defineRecord`;
- `defineView`;
- `defineAction`;
- `defineFunction`;
- `defineSettings`;
- `defineEvent`;
- `defineAutomation`;
- `defineSearch`;
- `defineAIIntegration`;
- `defineDiagnostics`;
- `defineHealth`;
- `definePermission`;
- `defineCapability`.

The SDK does not execute untrusted code, call providers, or bypass the host policy engine.
